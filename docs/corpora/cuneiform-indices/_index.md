# Cuneiform corpus indices

[[docs/corpora/_index|..]]

[[docs/corpora/cuneiform-indices/cdli|cdli]]: Catalogue artifacts and ATF text versions in the local CDLI snapshot, by language, period, genre, provenience and archive.

[[docs/corpora/cuneiform-indices/oracc|oracc]]: Archives, editions and tokens in the local ORACC snapshot, by family, project, period, genre and language.

***

Both describe the local snapshot that the fetch manifests reproduce. The counts are that snapshot's, and its
machine statistics (`cdli-stats.json`, `oracc-stats.json`) give the exact timestamp and checksums. Keep object,
edition, line and token apart: CDLI holds eight P-numbers with two distinct ATF versions each, and ORACC holds
alternate project editions of the same object.

SEAL (CC BY-NC-ND), DAPCA (CC BY-NC-SA), EUPT, the Ugarit Texts Database and EbDA (research-use only) are not
indexed here; their terms do not allow redistribution, or have not been checked.
