# Hurrian names

[[wiki/names/hurrian/_index|..]]

[[wiki/names/hurrian/names/A_KI_PI_E_TE|A_KI_PI_E_TE]]: Akipe-te: Akipe-te, '(Teššup) brought' (Hurrian personal name, hypocoristic). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/A_RA_NA_RE|A_RA_NA_RE]]: Aranare: personal name; Ugaritic ålnr (Hurrian), Linear B a-ra-na-ro. Hurrian, CANDIDATE.

[[wiki/names/hurrian/names/A_RE_DA_I|A_RE_DA_I]]: Ar-tae: Ar-tae (personal name; Hurrian ar- 'give'). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/A_RO_TE|A_RO_TE]]: Ḫaluti: Ḫaluti (woman's name, seal owner); rival ʾālôt 'oaths, curses'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/A_RU|A_RU]]: Ḫaru: Ḫaru (Hurrian personal name); rival the Semitic name Ḫayru 'Excellent'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/A_RU_DA_RA|A_RU_DA_RA]]: Arum-adal: Arum-adal (Hurrian personal name), ar=o=m-adal 'The Strong one gave him'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/A_SE_TU_star21F|A_SE_TU_star21F]]: Aštuḫḫa: Female (Hurrian personal name); rival the line as a heading, 'female (ones)'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/A_SU_JA|A_SU_JA]]: Azzuya: Azzuya (woman's name; Hurrian hypocoristic on az(z)-). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/DA_KU_SE_NE|DA_KU_SE_NE]]: Takušenni: Hurrian personal name, 'the brother is beautiful'; cf. Boğazköy Tagu(b)-šini, Ugaritic Taki-šenni. Hurrian, PROBABLE.

[[wiki/names/hurrian/names/DA_KU_SE_NE_TI|DA_KU_SE_NE_TI]]: Takušenni-ti: Hurrian personal name Takušenni with final TI. Hurrian, PROBABLE.

[[wiki/names/hurrian/names/DI_KI_SE|DI_KI_SE]]: Dikise: Dikise, personal name, Hurrian tagiše 'beauty'. Hurrian, CANDIDATE.

[[wiki/names/hurrian/names/I_PA_SA_JA|I_PA_SA_JA]]: Ipšaja: Ipšaja (personal name; Hurrian hypocoristic). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/KA_U_DE_TA|KA_U_DE_TA]]: Kaw-tatta: Kaw-tatta (Hurrian personal name), kaw- + tatt- 'love'; rival Ugaritic PN kwt. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/KA_U_ZU_NI|KA_U_ZU_NI]]: Kawṯuni: Kawṯuni (Hurrian personal name Kaw-šuni); rival Kawṯān, Heb. Kûšān. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/KU_KU_DA_RA|KU_KU_DA_RA]]: Kukkadal: Kukkadal (Hurrian personal name), kukk- + adal 'strong'; rival ḳdr 'dark'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/KU_PA_ZU|KU_PA_ZU]]: Kapizzi: Kapizzi (Hurrian personal name), 'kapizzi-jewel'; rival kupṯu 'headdress'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/KU_TU_KO_RE|KU_TU_KO_RE]]: Kutukkore: Kutukkore (Hurrian personal name). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/O_TE_JA|O_TE_JA]]: Ḫuteya: personal name, Hurrian Ḫutiya. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/PA_SE|PA_SE]]: Pašše: Pašše (personal name; Hurrian pašš- 'send'). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/PA_SE_JA|PA_SE_JA]]: Paššiya: Paššiya (personal name; Hurrian hypocoristic on pašš- 'send'). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/QA_KI_SE_NU_TI|QA_KI_SE_NU_TI]]: Kaki-šenni-ti: personal name, Hurrian type in -šenni 'brother'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/QA_TI_DA_TE|QA_TI_DA_TE]]: Kati-tati: Kati-tati (Hurrian personal name); rival katītat 'beaten (oil)'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/QA_TI_KI|QA_TI_KI]]: Kattike: Kattike (Hurrian personal name), on kad- 'to say'; rival katki 'utterance'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/SA_TA|SA_TA]]: Šata: Šata (personal name, heading the second section); rival śadā '(those of) the field'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/SE_SA_PA3|SE_SA_PA3]]: Zizapa: Zizapa (Hurrian personal name), ziz- 'chest'; rival Amorite ʿIziz-ab. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/TA2_TA_RE|TA2_TA_RE]]: Tatare: personal name (Hurrian); cf. Linear B ta-ta-ro, Mari ᶠTatara. Hurrian, CANDIDATE.

[[wiki/names/hurrian/names/TA2_TI_TE|TA2_TI_TE]]: Tati-te: Tati-te, '(Teššup) loved' (Hurrian personal name, hypocoristic). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/TA_RI_NA|TA_RI_NA]]: Tarinna: Tarinna (Hurrian personal name), stem tarinn-; rival trn 'mast'. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/TA_TA|TA_TA]]: Tatta: Tatta (Hurrian personal name), stem tatt-; rival the Anatolian name Tata. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/TE_KE|TE_KE]]: Tegi: Tegi (personal name; spelling of TE-KI). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/TE_KI|TE_KI]]: Tegi: Tegi 'Beautiful' (personal name; Hurrian tagi/tegi 'beautiful'). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/TU_NU|TU_NU]]: Tunu: Tunu (Hurrian personal name, owner's name on a double axe). Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/TU_SU_PU2|TU_SU_PU2]]: Tešub: Teshub (Hurrian storm god theophoric PN). Hurrian, CANDIDATE.

[[wiki/names/hurrian/names/U_TI|U_TI]]: Utti: Utti (Hurrian personal name), stem utt-; rival the Anatolian name Utti. Hurrian, SPECULATIVE.

[[wiki/names/hurrian/names/ZU_DI_RA|ZU_DI_RA]]: ṯudira: waitress, girl (Ug. ṯdr, a Hurro-Hittite loan from šiduri); rival the name Šituri. Hurrian, CANDIDATE.
