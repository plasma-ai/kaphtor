### Note

Personal name on HT128a, with GRAIN. The closest name is Nuzi Mittar-atti, element mittar- (Gelb, Purves, and MacRae 1943, s.v. MITTAR-ATTI), which Gelb sets among the non-Hurrian names with apparent Kassite features (ibid., 196) and Gentile analyses as Mitanni Indo-Aryan \*mitra-atthi- 'having Mitra \[or a friend\] as his guest' (Gentile 2019, 157); no Kassite element list has mittar- (Clay 1912, 36–41; Pinches 1917, 111–113). Rival: Indo-Aryan -mitta, as Amarna Ša-mitta (Gelb, Purves, and MacRae 1943, element list, s.v. šu). Bare MI-TA occurs only on HT128a; SI-MI-TA (HT96a), A-MI-TA (ZA10b) and the Troy whorls contain the string but are separate words. Cross-reference: SI-MI-TA, MI-DA (t/d variant), A-MI-DA-O.
