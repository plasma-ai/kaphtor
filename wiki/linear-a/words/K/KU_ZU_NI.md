### Note

HT 13 KU-ZU-NI 18, in the KA-U-DE-TA wine list; HT 85a KU-ZU-NI 5, in a roster counted in men; both tablets also list DA-SI-\*118. ZU = /ṯu/: kuṯ(i)n-. Ugarit has the personal name kṯn, syllabic ki-še-na, ki-ši-na, ku-ši-nu, etym. unc. (DULAT s.v. kṯn (I), citing Huehnergard UVST 231 nn. 91 f.). Rival: Ug. ktn 'tunic' (DULAT 464), which has t, not ṯ. Weak point: ZU = /ṯu/ is a proposed value.

### Note

HT 85a KU-ZU-NI 5, in a roster counted under VIR; HT 13 KU-ZU-NI 18, in the KA-U-DE-TA wine list (KU-RO 130½). Compare the Ugaritic personal name kṯn, syllabic ki-še-na, ku-ši-nu, etymology uncertain (DULAT). Rival: Ug. ktn 'tunic', which has t, not ṯ. Weak point: the choice rests on ZU = /ṯu/, which is unconfirmed, so the name supports that value without confirming it.
