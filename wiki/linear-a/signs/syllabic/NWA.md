**Status: conventional.** The conventional value carried over from Linear B.

## Phonetic value

| Field | Value |
|---|---|
| Value | /nwa/ |

| Linear B | B 48, value nwa |
| Linear B Unicode | U+10045 LINEAR B SYLLABLE B048 NWA |
| Neutralization class | none |

### Forms cited for the value

- Linear B \*48 = nwa, a sign with a graphic antecedent in Linear A (Salgarella 2023, 410)
- JA-I-NWA-RO (SY Za 4), its one Linear A token, reads with the Linear B value

### Note

One token, on the Kato Syme libation table SY Za 4, the first AB 48 in Linear A and one its editors expected (Muhly and Olivier 2008, 207–8, 216 and n. 22, after Ventris and Chadwick 1956, 40). Cretan Hieroglyphic has it as CH 006 (Salgarella 2020, 212 n. 104), and Del Freo's phonographic signary of Linear A counts it (Petrakis and Salgarella 2026, 31, Fig. 0.1, after Del Freo 2023, 81). Linear B nwa alternates with nu-wa, pe-ru-si-nwa beside pe-ru-si-nu-wa (Salgarella 2023, 410).
