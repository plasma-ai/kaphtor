# *43

[[wiki/linear-a/signs/syllabic/_index|..]]

***

<!-- BEGIN kaphtor:record -->

**Status: conventional.** The conventional value carried over from Linear B.

## Phonetic value

| Field | Value |
|---|---|
| Value | /ai/ |
| Alternates | none |
| Linear B | B 43, value a₃ |
| Linear B Unicode | U+10041 LINEAR B SYLLABLE B043 A3 |
| Neutralization class | none |

### Note

One token, MY Zf 2, incised on one of the handle plates of a bronze cauldron from Shaft Grave IV at Mycenae (NMA 576); Salgarella calls it the only appearance of AB 43 in Linear A (2020, 375 n. 3) and says the sign "might have been present" there (212 n. 103, after Palaima 2003b). Melena lists \*43 among the signs Mycenaean scribes added to the syllabary, yet holds that it "was perhaps already attested by the time of Shaft Grave IV" and that "a Linear A source cannot be ruled out" (2014, 87 and n. 114). In Linear B a₃ writes /ai/ at word start only (Salgarella 2020, 39). AB 43 is absent from Del Freo's phonographic signary of Linear A (Petrakis and Salgarella 2026, 31, Fig. 0.1, after Del Freo 2023, 81).
