# NO

[[wiki/linear-a/signs/syllabic/_index|..]]

***

<!-- BEGIN kaphtor:record -->

**Status: conventional.** The conventional value carried over from Linear B.

## Phonetic value

| Field | Value |
|---|---|
| Value | /no/ |
| Alternates | none |
| Linear B | B 52, value no |
| Linear B Unicode | U+1001C LINEAR B SYLLABLE B052 NO |
| Neutralization class | none |

### Note

NOT A LINEAR A SIGN. AB52 NO occurs nowhere in the Linear A corpus or SigLA, and Unicode's Linear A block has no AB052; the value no is Linear B's. Its two former confirmations came from Brice's edition of the texts, which read I as no: from it Gordon took ya-ta-no (Brice I 14) and no-x-na-ma (I 13), GORILA's JA-TA-I-\*301-U-JA (AP Za 1) and I-PI-NA-MA (AP Za 2) (Gordon 1966 §163). Del Freo's current phonographic signary of Linear A leaves it out (Petrakis and Salgarella 2026, 31, Fig. 0.1, after Del Freo 2023, 81). Do not propose NO in Linear A spellings.
