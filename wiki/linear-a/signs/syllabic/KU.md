# KU

[[wiki/linear-a/signs/syllabic/_index|..]]

***

<!-- BEGIN kaphtor:record -->

**Status: conventional.** The conventional value carried over from Linear B.

## Phonetic value

| Field | Value |
|---|---|
| Value | /ku/ |
| Alternates | /gu/, /qu/ |
| Linear B | B 81, value ku |
| Linear B Unicode | U+10013 LINEAR B SYLLABLE B081 KU |
| Neutralization class | K |

### Alternate values

| Value | Confidence | Evidence |
|---|---|---|
| /gu/ | 0.50 | KU-PA₃-NU = Gupanu (Gordon: g-p-n 'vine') |
| /qu/ | 0.30 | K-class neutralization |

### Forms cited for the value

- KU-NI-SU = kunāshu (Gordon 1966: emmer wheat)
- KU-PA₃-NU = Kubānu (Gordon 1966: Gupanu)
- KU-DO-NI (Gordon PN)

### Note

No CH ancestor—Linear A innovation, possibly from MM flying bird motif (Ferrara et al. 2022)
