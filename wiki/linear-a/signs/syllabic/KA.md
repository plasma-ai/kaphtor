# KA

[[wiki/linear-a/signs/syllabic/_index|..]]

***

<!-- BEGIN kaphtor:record -->

**Status: conventional.** The conventional value carried over from Linear B.

## Phonetic value

| Field | Value |
|---|---|
| Value | /ka/ |
| Alternates | /ga/, /qa/ |
| Linear B | B 77, value ka |
| Linear B Unicode | U+1000F LINEAR B SYLLABLE B077 KA |
| Neutralization class | K |

### Alternate values

| Value | Confidence | Evidence |
|---|---|---|
| /ga/ | 0.40 | K-class neutralization |
| /qa/ | 0.30 | K-class neutralization |

### Forms cited for the value

- A-KA-NU = agānu (Gordon: 'bowl')
- KA-RO-PA₃ = karpu (Gordon: 'vase')
- KA-DU-MA-NE (Gordon PN)

### Note

No CH ancestor—Linear A innovation, possibly from MM seal whirl motif (Ferrara et al. 2022)
