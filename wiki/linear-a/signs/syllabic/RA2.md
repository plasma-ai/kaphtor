# RA2

[[wiki/linear-a/signs/syllabic/_index|..]]

***

<!-- BEGIN kaphtor:record -->

**Status: conventional.** The conventional value carried over from Linear B.

## Phonetic value

| Field | Value |
|---|---|
| Value | /la/ |
| Alternates | none |
| Linear B | B 76, value ra₂ |
| Linear B Unicode | U+10048 LINEAR B SYLLABLE B076 RA2 |
| Neutralization class | R |

### Forms cited for the value

- PU-RA₂ compared with Bōlu/Baʿal by Gordon (candidate lexical identification)
- RA2 specifically marks /la/ distinct from RA = /ra/

### Note

The only sign that reliably distinguishes /l/ from /r/ in Linear A.
