# WE

[[wiki/linear-a/signs/syllabic/_index|..]]

***

<!-- BEGIN kaphtor:record -->

**Status: conventional.** The conventional value carried over from Linear B.

## Phonetic value

| Field | Value |
|---|---|
| Value | /we/ |
| Alternates | none |
| Linear B | B 75, value we |
| Linear B Unicode | U+10038 LINEAR B SYLLABLE B075 WE |
| Neutralization class | none |

### Note

NOT A LINEAR A SIGN. AB75 WE occurs nowhere in the Linear A corpus or SigLA, and Unicode's Linear A block has no AB075; the value we is Linear B's. Its former confirmations came from Brice's edition of the texts, which read RI as we: from it Gordon took da-we-da (HT 10a, 85a, 93a, 122a) and ma-ka-we-te (HT 87, 117a), GORILA's DA-RI-DA and MA-KA-RI-TE (Gordon 1966 §§133, 136, 163). Del Freo's current phonographic signary of Linear A leaves it out (Petrakis and Salgarella 2026, 31, Fig. 0.1, after Del Freo 2023, 81). Do not propose WE in Linear A spellings.
