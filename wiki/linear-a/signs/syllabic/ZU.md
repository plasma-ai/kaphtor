**Status: proposed.** A proposed value.

Evidence: ṯ 15/21, n and m 16/21; A-ZU-RA yields a root under every rival. ṯ reads 6 of 8 context words, z reads RU-ZU-NA (PS \*z), so ZU writes both

### Forms cited for the value

- A-ZU-RA = ʾAṯirat (KNZc7 incantation bowl)—divine name on ritual vessel
- Linear B Z-series lacks ZU; B79 undeciphered with 3–4 attestations (Judson 2020)—predicted if interdental value
- No ṯ→z merger in Semitic typology—/zu/ cannot approximate /ṯ/
- Phonemic gap: interdental /ṯ/ is open; /z/ already covered by ZA
- Complementary distribution: ZA-SI-ZU (ARKH4b)—ZA and ZU in same word, proving different phonemic classes
- MA-ZU = maṯu 'child/male' (HT102)—supportive PS #1702 match
- Cross-script parallel: Linear B ma-\*79 ↔ Linear A MA-ZU—potential independent confirmation
- KU-ZU-NI = Kuṯinu (HT 13, HT 85a), the Ugaritic personal name kṯn, syll. ku-ši-nu (DULAT 467)
- ZU-JU-PU₂ = ṯulubu 'flute' (HT 25a), sign for sign Ugaritic ṯlb (DULAT 892)
