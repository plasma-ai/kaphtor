# Cypro-Minoan Deterministic Statistical Kernel Suite (CM-G, CM-E, CM-O, CM-B, CM-I, CM-H)

All inputs are T5-compliant (published CC BY 4.0 readings and metadata only; zero raw Valério 2016 Appendix A sign-group transcriptions and zero canonical §7 held-out texts).

## Methodological & Epigraphic Controls

1. **Amathus *IG XV 1* strict filter (`parse_ig_amathus`):** Selects strictly Amathus Eteocypriot parts from `data/ane/ig-xv-1-cypriot/records.jsonl`, excludes non-Amathus sites (Kurion, Marion, unprovenanced `IG XV 1, 16`), excludes tentative attributions (`IG XV 1, 12`, `language_label_basis == "tentative"`) and direction-doubtful inscriptions (`←?` / `→?`), rejects lacuna-adjacent fragments (`]` / `[`), and restores EpiDoc `<lb/>` boundaries to yield exactly **`92` confirmed** (`90` `L >= 2`, `71` `L >= 3`) and **`66` strictly undotted** (`64` `L >= 2`, `50` `L >= 3`) word types.
2. **In-script Cypriot Syllabic Greek & Linear B calibration (`parse_ig_cypriot_greek`):** Parses `194` unbroken `L >= 2` Cypriot Syllabic Greek word types from *IG XV 1* (exact daughter script of Cypro-Minoan) and `2,545` CSET-filtered DAMOS Linear B types (`9` of `2,554` clean Linear B types carry non-Cypriot `au-` diphthongs). `CM-I1` identifies Linear B as **`greek` #1** in both modes (`p_M = 0.0415` `plene`, `0.0115` `omission`) and Cypriot Greek as `greek` #1 (`p_M = 0.0540`). In 8-way `CM-I2` (`N = 90`), Cypriot Greek passes decisively as **`greek` #1** in both modes (`+85.27, p_M = 0.0040` `plene`; `+90.70, p_M = 0.0370` `omission`) and rejects `amathus_ec` (`-278.44, p = 0.9255`).
3. **Unbiased size-matching, clean corpus loaders & Egyptian boundary:** `CM-I2` averages 200 size-matched (`N = 90` / `64`) draws in **log-probability space (`mean_200(log P_d)`)** rather than probability space (`log(mean(P_d))`), removing Jensen's inequality bias against single-sample Amathus EC and suppressing Monte Carlo jitter. Latin deduplicates clean alphabetic forms across all `816,985` rows of `latinf_forms.jsonl` before uniform sampling (eliminating `#DEF#` and paradigm-row multiplicity bias); Sumerian filters ORACC morphological glosses to strict lowercase phonetic normalizations with `ŋ/ĝ → n` (`467` `plene` / `319` `omission` types); Semitic balances OSHB Hebrew (handling silent sheva, medial/final matres lectionis `י`/`ו`, and geminated consonantal `וּ`) 50/50 with ORACC Akkadian. TLA/ORAEC Egyptian is unvocalized (consonantal script) and omitted from vocalized CV models to avoid synthetic vowel insertion.
4. **Honest ceilings:**
   - Under `CM-E` strict `V`-vs-`CV` nulls, deduplicated `L >= 3` consonant-skeleton stems (`csk_stems = 2` on **`ta-ra-*`** [`ta-ra-we`, `ta-ra-wo`] and **`a-sa-*`** [`a-sa-na` ↔ Amathus `a-so-na`]) do not reach `p < 0.05` (`p_vcv = 0.1144` confirmed / `0.0920` undotted), nor does Valério confirmed `suf2` (`p_vcv = 0.0685`).
   - Under `CM-I2`, combined `CM 1+2` passes `amathus_ec` #1 across all 4 mode × tier arms (`p = 0.0035–0.0365`) and `CM 2` alone ranks `amathus_ec` #1 in true Cypriot `cypriot_plene` (`+19.81, p = 0.0605`), while in coda-dropping `omission` `CM 2` alone is a near-tie with `hurrian` (`+0.79`, `amathus_ec p = 0.0370` vs. `hurrian p = 0.1394`).
   - Under `CM-H`, clay-ball `SEQ_1` (`40` tokens / `36` types) ranks `amathus_ec` #1 without reaching permutation significance (`p_M = 0.3527`), `SEQ_2` (`N = 5`) is underpowered, and isolated-sign acrophony (`19` tokens / `14` distinct signs) rejects a suffix origin (`p_vs_fin = 0.0002`) without yet beating the all-position CM 1 baseline (`p_vs_all = 0.2368`).
