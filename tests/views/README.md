# View tests

Tests for the record wiki's builder in `tools/views/`. Most run on a fixture written to a temporary folder. The
six live tests read `data/linear-a/` and are skipped until all seven files `model.load` reads are in the checkout, and one runs
plasma-wiki's `wiki` command and is skipped when it is not installed.

| Test | Covers |
|---|---|
| `test_views.py` | `counts`: documents from records (sides fold, HT 154's fragments stay apart), the census classes (every document in one class, a broken class file refused, 1,603 documents live), the complete-translation rule; `model`: the translation normalizer over both schemas, slugs and page paths (no collision live), sign status by kind (conventional only for a Linear B syllable, so not the *118 talent or *47 with no value; a proposal with or without evidence) and evidence opening with a verdict label refused, sign keys meeting forms whichever way the subscript is written (live: TA2, RA2 and PA₃); `markdown`: escaping, doubled brackets that never read as a damaged wikilink, wikilinks in table cells and labels with no bracket, the frontmatter round trip, the block splice that keeps text outside the block and every frontmatter line it does not own; `render`: a word page's attestations from every record, links to a page held by a translation alone, no "None" for a missing reading (live: every word page), a tier-4 page's reviewer and the outside scholar who published the reading (and no Review section without them), a name with no lexicon entry of its own giving its onomasticon reading and meaning and linking the lexicon entry it is read under, alternates and Linear B written as text (an alternate's value over its key: ṯ̣u, keyed ẓ), a proposed sign's evidence shown without a verdict, two pages on one path refused case aside, every link naming a page the build writes, no `name` or `sources` key (they are `wiki update`'s), the override folders; `indexes`: folder descs naming the site, the series and the first sign, for exactly the folders above the pages, a doubtful site ("(?)") read as a doubtful attribution, descs by hand from `overrides.json` where their folder exists (live: every one of them), the Keftiu spell filed under `LMP/` with no series folder; `ledgers`: the `counts` page from the data and never a stored `stats` block, the census and sign-status tables, the `standing` table with every lexicon entry once by tier, root groups with no root links, `by_sign` counting subscript forms; `aegean`: no pages without their files, ASCII page names and no two ids on one path, Eteocretan text in a code block and no `campaign_*` field, the Amathus control not called Eteocretan, the Phaistos sign bridge merged and no file metadata (authors, edit dates); `build`: backups to the user's state folder and never beside the wiki, a folder desc written only where none is, `--check` by default and writing nothing, deterministic `--write`, stale and orphaned pages, a backup of each changed page, `--prune`, refusal of uncommitted changes inside git and of pages it did not write, its pages seen inside a dot folder such as `~/.config`, no page path leaving the wiki folder, two sources writing one page refused, and (with `wiki` installed) the builder and `wiki update` settling on one tree rooted above `wiki/`, before and after a data change, with `wiki lint` clean |
| `test_roots.py` | `roots`: one page per record of `semitic_roots.json`, filed by first radical; no file, no pages; the page shows the root, its reflexes and the note; a project root names no SED entry; each radical folder's desc |
| `test_census_doc.py` | `census_doc`: `--check` writes nothing, `--write` fills only the blocks after a copy, the class table and its total, the GORILA V check summing to its total, the copy going to the backups folder by default, refusal of a missing or unknown block; live, the doc is current and its data counts sit only in blocks; no model name or private path in the doc |

Run with `PYTHONDONTWRITEBYTECODE=1 uv run --with pytest python -m pytest tests/views`.
