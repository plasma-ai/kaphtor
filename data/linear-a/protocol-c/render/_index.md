# Protocol C renderer table

[[data/linear-a/protocol-c/_index|..]]

[[data/linear-a/protocol-c/render/series.json|series.json]]: The one articulatory table that maps every arm's phonemes, and later the controls' and the nulls', to Linear B consonant series.

***

§5.5 item 1 of [the pre-registration](../../../../docs/protocol-c-preregistration.md) fixes the table by place and
manner; `series.json` states it, decides the phonemes the protocol leaves unnamed, and adds the three rules made
after the Luwian pilot (gemination written single, Yakubovich's cover symbol T, digraphs joined). The renderer
that reads it is phase C2 and is not yet written, so no inventory here has been rendered.
